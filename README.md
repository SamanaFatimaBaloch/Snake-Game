# Snake-Game
This is a classic Snake Game developed using HTML, CSS, and Vanilla JavaScript, focused on strengthening core front-end development and logic-building skills. The game features smooth real-time snake movement controlled through keyboard arrow keys, dynamic food generation, score tracking, and a high score system that is stored using localStorage so it persists across sessions. It also includes a game timer, wall collision detection that triggers a game over modal, and a restart functionality to replay the game without refreshing the page. The project heavily uses DOM manipulation to dynamically create and update the game board grid, along with arrays and objects to manage the snake’s movement and position. It demonstrates important concepts such as event handling, interval-based game loops, collision detection, and state management, making it a strong practice project for understanding interactive web application development.
